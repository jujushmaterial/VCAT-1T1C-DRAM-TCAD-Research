- **담당 단계:** 미정
- **현재 작업:** 없음

## 이 폴더에 기록할 내용

- `timeline/`: 날짜별 작업 기록
- `working_files/`: 수정·시험 중인 TCAD 코드
- `result_notes/`: 결과 해석, 비교표, 그래프 설명
- `handoff/`: 다른 연구원이 이어서 작업할 수 있는 인수인계

## 작업 원칙

1. 작업 시작 전 해당 Phase Issue에서 담당자와 상태를 확인합니다.
2. 코드와 결과의 조건을 날짜별 기록에 남깁니다.
3. 대용량 TDR·PLT·DAT·LOG는 연구실 서버에 두고 경로만 기록합니다.
4. 검토가 끝난 기준 코드와 결과만 `shared/`에 반영합니다.
5. 작업 종료 시 다음 작업자가 시작할 파일과 남은 일을 `handoff/`에 적습니다.
