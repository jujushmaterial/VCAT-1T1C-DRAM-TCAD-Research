# 주상현 작업 공간

이 폴더는 개인 작업 과정과 인수인계를 기록하는 공간입니다. 검토가 끝난 기준 파일은 `shared/`에 반영합니다.

## 담당 단계

- Phase 1. 기존 Planar 구조의 작동 원인 확인

## 현재 작업

- 기존 Planar 구조의 공통 조건 정리
- S0, G0, D0, DG 네 구조 비교 준비

## 권장 하위 폴더

- `timeline/`: 날짜별 작업 기록
- `working_files/`: 수정·시험 중인 코드
- `result_notes/`: 결과 해석과 비교표
- `handoff/`: 다른 연구원이 이어서 작업할 수 있는 인수인계

## 현재 상태

- **상태:** Phase 1 시작 준비
- **관련 Issue:** [Phase 1](../../issues/1)
- **서버 원본 위치:** 미정
- **현재 문제:** 없음

## 작성 원칙

1. 작업한 날짜와 목적을 기록합니다.
2. 사용한 코드와 입력 조건을 적습니다.
3. 결과 파일과 서버 경로를 남깁니다.
4. 오류가 있으면 숨기지 않고 재실행 조건을 기록합니다.
5. 작업을 멈출 때 다음 작업자가 시작할 파일과 순서를 적습니다.
