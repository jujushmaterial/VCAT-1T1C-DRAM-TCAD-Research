## 필수 기록 규칙

이 폴더 아래에서 파일 또는 폴더를 생성·수정·삭제·이동·이름 변경하면, **같은 작업 또는 같은 커밋에서 반드시 [`TIMELINE.md`](./TIMELINE.md)에 기록을 추가합니다.** 타임라인이 갱신되지 않았다면 작업은 완료되지 않은 것으로 간주합니다.

## 폴더 용도

- `phases/`: Phase와 결과물 ID별 제출본
- `working_files/`: 수정·시험 중인 TCAD 코드
- `result_notes/`: 결과 해석, 비교표, 그래프 설명
- `handoff/`: 다음 연구원을 위한 인수인계
- `TIMELINE.md`: 개인 폴더 전체 변경 이력

## 작업 원칙

1. 작업 시작 전 해당 Phase Issue에서 담당자와 체크리스트를 확인합니다.
2. 코드와 결과의 조건, 단위, 실행 여부를 기록합니다.
3. 대용량 TDR·PLT·DAT·LOG는 연구실 서버에 두고 경로만 기록합니다.
4. 검토가 끝난 기준 코드와 결과만 `shared/`에 반영합니다.
5. 기존 제출본은 삭제하거나 덮어쓰기보다 새 버전으로 남깁니다.
6. 작업 종료 시 변경 파일, 결과, 문제, 다음 작업을 `TIMELINE.md`에 남깁니다.
