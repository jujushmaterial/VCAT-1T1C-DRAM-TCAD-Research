# P01-T10-O01 통합 결론 보완본

현재 GitHub에 이미 올라간 핵심 그림, profile 그림과 terminal metrics CSV는 다시 포함하지 않는다. 본 보완본은 산출물 요구사항의 텍스트 부분인 통합 결론과 근거 매핑을 추가한다.

## 포함 파일

- `P01-T10-O01_integrated_conclusion.md`: Dual-WF 작동 원인 통합 결론
- `P01-T10-O01_evidence_map.csv`: 결론 문장과 기존 산출물 근거의 대응
- `data/P01-T10-O01_terminal_metrics_with_dibl_sign.csv`: 기존 |DIBL|과 signed shift를 구분한 표

## 핵심 제한

- Gap은 고정되어 Gap 효과를 평가하지 않았다.
- 기존 DIBL은 gm-tangent Vth의 절대 이동량이며 conventional DIBL로 확정하지 않는다.
- 전류 절대 단위 normalization은 미확인이다.
- 2D color scale보다 동일 cutline을 우선한다.
- TCAD 재실행이나 새로운 profile 추출은 하지 않았다.
