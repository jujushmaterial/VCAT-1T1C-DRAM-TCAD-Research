## 제출 메모

P5 exact 49-point Forward data에서 계산한 P7 sensitivity/interaction 그래프. Local normalized sensitivity, Ioff/Ion-Ioff log sensitivity, B1/B2 OAT response, conditional DIBL slope, DIBL 및 log10(Ioff)의 mixed finite-difference interaction을 포함한다. 기존 P5 Map의 재사용이 아니라 P8 변수선정과 2D Grid 필요성을 판단하기 위한 Phase-7 분석 시각화이다. GIDL은 49-point complete data가 없어 sensitivity graph를 만들지 않았다.
