## 제출 메모

P03-T15-O06 — Electric Field·Emax 비교

G0/G1/G2는 동일 GIDL 최종 상태(storage=1.0 V, gates=-0.4 V)에서 비교한다.
2D ElectricField contour의 color scale은 각 화면의 자동 range일 수 있으므로 색 자체보다 legend의 Emax와 hot-spot 위치를 우선 해석한다.
G1/G2 BTBT 및 ConductionBand 화면은 field 변화가 실제 tunneling/barrier 분포와 어떻게 연결되는지 보조 확인하기 위해 함께 첨부한다.
