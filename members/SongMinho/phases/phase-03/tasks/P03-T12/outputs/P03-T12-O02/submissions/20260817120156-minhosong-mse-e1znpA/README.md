## 제출 메모

P03-T12-O02 — 양방향 구조 비교 이미지

Dual-Metal 두 방향은 geometry 자체를 뒤집는 것이 아니라 동일한 30/30 nm 구조에서 WF_SN/WF_BL의 순서를 바꾸는 방식이다.
SWB 화면은 RatioSN=0.5와 다섯 WF 배치 조합을 확인하는 원본 실행조건 증거이다.
대표 CBE 화면은 ΔWF=0, +0.4, -0.4 조건에서 동일 geometry를 사용하면서 WF 공간 배치에 따라 내부 barrier profile이 달라지는 것을 보여준다.

이 출력은 구조/배치 확인용이며 정량 barrier 비교는 P03-T12-O06의 동일 위치 C1 cutline을 우선 사용한다.
