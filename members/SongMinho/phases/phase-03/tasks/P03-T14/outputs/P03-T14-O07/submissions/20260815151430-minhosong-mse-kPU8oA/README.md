## 제출 메모

P03-T14-O06에서 확정한 P3 Fixed WF를 P4~P9 전달값으로 기록한다.

- M1 LOW = Ti, 4.33 eV
- M2 HIGH = TiN, 4.70 eV
- M3 LOW = Ti, 4.33 eV

P4~P9에서는 WF를 다시 Sweep하지 않는다.
현재 P3 1:1:1 geometry는 P4 기본 동작 확인을 위한 대표 기준구조이며,
최종 optimized geometry로 선언하지 않는다.
P5에서는 Fixed WF를 유지하고 두 metal boundary를 독립변수로 최적화한다.
