## 제출 메모

ocal Mesh의 공간별 역할을 A/B/C/E로 정리했다. A는 outer/quiet coarse 영역, B는 gate/channel medium 영역, C는 SN/BL junction support 영역, E는 gate-edge/Si-SiO2/high-field fine contour 영역이다. Fine contour 좌표는 측정 hotspot 경계가 아니라 보수적인 engineering candidate이다.
