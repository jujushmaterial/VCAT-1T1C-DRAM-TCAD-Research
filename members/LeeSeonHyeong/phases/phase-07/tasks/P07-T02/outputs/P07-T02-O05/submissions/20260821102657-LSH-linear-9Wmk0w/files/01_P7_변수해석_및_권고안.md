# P7 변수 해석 및 권고안

## 1. 이번 정리의 목적

Phase 7에서는 P5에서 확보한 Metal Boundary Sweep 결과를 재사용하여 Geometry Sensitivity를 정리하고, P8에서 사용할 핵심 Geometry 변수를 결정한다.

이번 검토에서는 기존 보고서에서 사용한 표현을 우선하여 다음과 같이 용어를 통일한다.

- **첫 번째 Metal Boundary 위치**: `Xbnd1_nm`
- **두 번째 Metal Boundary 위치**: `Xbnd2_nm`
- **M1 / M2 / M3 segment**
  - M1: Low-WF 영역
  - M2: 중앙 High-WF 영역
  - M3: Low-WF 영역
- 기존 작업 대화에서 사용한 `B1`, `B2`는 각각 `Xbnd1`, `Xbnd2`와 같은 값을 가리키는 약칭이다.

Phase 3 보고서에서는 L-H-L Three-zone VCAT을 M1/M2/M3로 분할하고, 두 Work Function 경계를 `metal boundary Xbnd`로 설명하고 있다. 따라서 이후 공유 문서에서도 `Xbnd1/Xbnd2`, `M1/M2/M3`, Low-WF/High-WF 표현을 우선 사용한다.

---

## 2. 독립 Geometry 입력과 파생값

현재 gate 구간은 20-80 nm로 고정되어 있으므로 각 segment 길이는 다음과 같이 결정된다.

- `M1Length = Xbnd1 - 20`
- `M2Length = Xbnd2 - Xbnd1`
- `M3Length = 80 - Xbnd2`

따라서 M1/M2/M3 segment length는 `Xbnd1`, `Xbnd2`가 주어지면 자동으로 정해진다.

즉, **Xbnd1/Xbnd2와 M1/M2/M3 length를 서로 다른 독립 Sweep 변수로 동시에 세면 동일한 L-H-L segmentation geometry의 자유도를 중복 계산하게 된다.**

Triple-material gate 선행연구에서도 M1/M2/M3에 각각 길이 L1/L2/L3를 부여하여 gate-length ratio에 따른 특성을 분석하지만, 전체 gate length가 정해져 있을 때 세 segment length는 서로 제약된다. 이는 segment length가 물리적으로 의미 있는 값이라는 근거이지, 현재 Xbnd1/Xbnd2에 추가되는 새로운 독립 자유도라는 근거는 아니다.

---

## 3. P8 핵심 Geometry 변수 권고

현재 P7 제출 결과와 P5/P6 데이터 구조를 함께 검토하면 P8의 독립 Geometry 변수는 다음 두 개를 유지하는 것이 가장 타당하다.

1. `Xbnd1_nm`
2. `Xbnd2_nm`

이유는 다음과 같다.

- P5 7x7 Boundary Sweep에서 두 Boundary 변화에 따른 전기적 변화가 실제로 확인되어 있다.
- P7 Local Slope에서 `Xbnd1`과 `Xbnd2` 모두 Ioff, Ion/Ioff, Vth, DIBL 등 주요 지표에 유의미한 변화 방향을 보인다.
- 한 Boundary의 효과 크기가 다른 Boundary 위치에 따라 달라지는 conditional-slope 변화가 있으므로 두 변수를 함께 보는 2D Grid가 필요하다.
- P6에서 이미 `Xbnd1_nm`, `Xbnd2_nm`가 tolerance 분석용 독립 parameter로 정의되었다.
- M1/M2/M3 length, segment ratio 등은 같은 geometry를 다른 방식으로 표현하는 파생값이므로 별도 독립 Sweep 축으로 추가하지 않는다.

따라서 현재 권고는 **P8의 TCAD 입력과 2D Window 정의는 Xbnd1/Xbnd2를 기준으로 유지**하는 것이다.

---

## 4. 현재 P7/P8에서 고정하는 항목

다음 값들은 P8의 새 Geometry 변수로 다시 열지 않는다.

- Work Function: 앞 Phase에서 선택한 Low-WF / High-WF 조합을 유지
- Gate oxide thickness
- Silicon pillar/body dimension
- Gate length
- Doping / junction profile

이 판단은 해당 항목들이 물리적으로 중요하지 않다는 뜻이 아니다. 선행연구에서는 oxide thickness, silicon thickness, gate length, doping 등이 threshold voltage, short-channel effect, floating-body effect 등에 영향을 줄 수 있음을 보고한다.

그러나 현재 P7의 목적은 **L-H-L Three-zone의 Metal Boundary 변화에 대한 Geometry Sensitivity와 P8의 2D Gate Segmentation Geometry Window를 정리하는 것**이다. 따라서 이전 Phase에서 고정한 device parameter를 다시 열어 연구 차원을 증가시키지 않는다.

---

## 5. P8 Sweep 범위는 현재 P7 제출본을 우선 사용

P07-T01-O05의 현재 handoff 범위는 다음과 같다.

- `Xbnd1_nm`: 33-37 nm, 1 nm step
- `Xbnd2_nm`: 63-69 nm, 1 nm step
- PASS/Marginal/FAIL transition이 확인되는 부근만 필요 시 0.5 nm adaptive refinement

이 범위는 **최종 공정 허용범위가 아니라 P8에서 Device-level Window를 찾기 위한 초기 campaign domain**이다.

따라서 P8 결과를 보기 전에 이 범위를 곧바로 "최종 tolerance"로 표현하면 안 된다.
