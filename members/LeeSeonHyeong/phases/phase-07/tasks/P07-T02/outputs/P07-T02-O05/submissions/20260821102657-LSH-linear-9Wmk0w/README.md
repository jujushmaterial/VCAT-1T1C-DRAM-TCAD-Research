## 제출 메모

본 자료는 Phase 7 Geometry 민감도 분석 과정에서 논의된 변수 정의, High-WF 영역의 폭/위치 해석, 추가 구조변수 Screening 수행 여부를 조원 간 공유하기 위해 정리하였다.

기존 GitHub 제출자료나 Phase 1~3 보고서 원본은 중복 첨부하지 않았으며, 필요한 자료의 위치만 마지막 문서에 기재하였다.

본 자료에서 Xbnd1, Xbnd2는 실제 TCAD Geometry 입력값이며, High-WF 영역의 폭과 위치 관련 값은 이 두 입력으로부터 계산되는 보조 해석값이다.

추가 구조변수 Screening 검토는 P07-T02 선택 산출물 O01~O03 수행 여부를 판단하기 위한 내부 검토이며, 최종 보고서의 정량 결과 자체가 아니다.

=> 요약: 근거가 부족한 것 같아 추가 시뮬레이션 진행 여부를 논의했으나, 현재 진행 상황 및 마감 기한 등을 고려하여 시뮬레이션 대신 논문 으로 논리 구조를 보강하는 방식을 제안한다. 참고한 논문 중에는 석사 논문도 포함되어있음을 미리 알린다. 시뮬레이션 진행 중 발생한 이슈를 제안하는 것 이므로 전체적인 흐름을 고려해 보고서 팀이 읽어보고 반영 여부를 결정하면 된다. 해당 파일의 내용은 P7을 진행한 이선형 조원과 송민호 조원의 의견이 반영되었다.
