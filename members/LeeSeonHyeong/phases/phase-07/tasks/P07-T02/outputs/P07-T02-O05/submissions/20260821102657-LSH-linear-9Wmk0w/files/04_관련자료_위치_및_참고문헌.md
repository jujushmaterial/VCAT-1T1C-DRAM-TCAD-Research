## 3. 이 패키지에 포함한 참고문헌

### [R1] Three-layer WF VCT - 직접 기준문헌

**Three-layer work-function gate for suppressing floating-body effects on vertical-channel DRAM access transistors**  
Applied Physics Letters, 2026  
DOI: 10.1063/5.0320207

패키지 파일:
- `References/R1_Three-layer_WF_VCT_APL_2026.pdf`

사용 목적:
- Vertical-channel DRAM access transistor에서 three-layer Work Function gate를 직접 다룸
- 양 끝 Low-WF로 junction GIDL을 억제하고 중앙 High-WF로 channel depletion을 유지하는 물리적 역할 설명
- 현재 L-H-L 구조의 가장 직접적인 외부 근거

---

### [R2] VCT Multi-Layer Gate 석사학위논문

**Floating-Body Effect Analysis and Multi-Layer Gate Engineering for Vertical-Channel DRAM Access Transistors**  
이승윤, 서강대학교 석사학위논문

패키지 파일:
- `References/R2_VCT_Multi-Layer_Gate_MS_Thesis_2026.pdf`

사용 목적:
- Gate length, body thickness, drain doping 등 다른 device parameter의 영향 확인
- Multi-layer Work Function gate와 floating-body effect 해석
- 다른 parameter를 "무민감해서 제외"하는 것이 아니라 연구범위 때문에 고정한다는 설명의 근거

---

### [R3] Triple Material Surrounding Gate MOSFET

**Performance analysis of fully depleted triple material surrounding gate (TMSG) SOI MOSFET**  
P. Suveetha Dhanaselvam, N. B. Balamurugan  
Journal of Computational Electronics, 2014  
DOI: 10.1007/s10825-014-0554-3

패키지 파일:
- `References/R3_Triple_Material_Surrounding_Gate_2014.pdf`

사용 목적:
- M1/M2/M3와 gate-length ratio를 설계 parameter로 다루는 선행연구
- oxide thickness, silicon thickness, doping concentration도 별도 device parameter로 분석
- segment length의 물리적 의미와 추가 후보변수의 존재를 동시에 설명

---

### [R4] Gate Misalignment 분석

**Dual-Material Double-Gate SOI n-MOSFET: Gate Misalignment Analysis**  
Rupendra Kumar Sharma et al.  
IEEE Transactions on Electron Devices, 2009  
DOI: 10.1109/TED.2009.2019695

패키지 파일:
- `References/R4_Dual_Material_Gate_Misalignment_2009.pdf`

사용 목적:
- 위치 변화가 surface potential, electric field, threshold voltage, subthreshold slope, DIBL, drain current 등에 영향을 줄 수 있다는 방법론 참고
- 중앙 High-WF 영역의 위치 보조해석에 참고

주의:
- 이 논문의 misalignment는 우리 L-H-L VCAT의 중앙 High-WF 영역 이동과 동일한 공정현상은 아니다.
- 직접 선행연구가 아니라 위치 민감도 해석 방법론 참고로만 사용한다.

---

### [R5] Triple-Material Double-Gate Analytical Model

**Two-Dimensional Analytical Modeling of Threshold Voltage of Doped Short-Channel Triple-Material Double-Gate (TM-DG) MOSFET's**  
Sarvesh Dubey, Dheeraj Gupta, Pramod Kumar Tiwari, S. Jit  
Journal of Nano- and Electronic Physics, 2011

패키지 파일:
- `References/R5_Triple_Material_DG_Analytical_Model_2011.pdf`

사용 목적:
- Triple-material gate를 세 영역으로 나누어 surface/channel potential을 해석하는 이론적 참고
- M1/M2/M3처럼 서로 다른 Work Function 영역이 공간적으로 구분되어 electrostatics에 작용한다는 보조 근거

## 4. 참고문헌을 사용할 때의 우선순위

이번 P7 해석에서 권장하는 사용 순서는 다음과 같다.

1. **R1** - 현재 VCT / three-layer WF 구조에 가장 직접적인 근거
2. **R2** - VCT의 다른 구조변수 및 FBE 관련 상세 근거
3. **R3** - triple-material gate의 segment length / gate-length ratio 근거
4. **R4** - 위치 변화 sensitivity 방법론 참고
5. **R5** - triple-material gate의 공간별 potential 해석 보조 근거

보고서에서는 R4를 중앙 High-WF 영역 위치 이동의 직접 실험 근거처럼 표현하지 않는 것이 중요하다.
