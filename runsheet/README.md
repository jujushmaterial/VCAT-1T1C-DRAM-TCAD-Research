# Run Sheet 운영 방법

Run Sheet는 현재 연구원이 해야 할 일과 다음 연구원이 이어서 할 일을 한곳에서 확인하기 위한 실행표입니다.

각 단계는 GitHub Issue 하나로 관리하며 다음 네 부분을 동일하게 사용합니다.

## 1. 해야 할 것

현재 단계에서 실제로 수행해야 하는 작업입니다. 한 체크박스에는 한 가지 작업만 적습니다.

## 2. 나와야 하는 결과물

작업이 끝났을 때 반드시 남아 있어야 하는 코드, 그래프, 표, 설명 문서입니다. 결과물이 없으면 단계 완료로 처리하지 않습니다.

## 3. 과정의 이유

이 단계를 왜 수행하는지 짧게 설명합니다. 복잡한 용어보다 이 단계에서 확인하려는 질문을 중심으로 작성합니다.

## 4. 다음 과정

현재 단계가 끝난 뒤 어떤 방향으로 진행하는지 요약합니다. 자세한 작업은 다음 단계 Issue에서 확인합니다.

## 상태 의미

- **대기:** 아직 시작하지 않음
- **진행 중:** 담당자가 작업 중
- **검토 중:** 실행과 결과 정리가 끝나 검토가 필요함
- **완료:** 결과물과 인수인계가 확인됨
- **문제 발생:** 오류 또는 선행 작업 부족으로 멈춤
- **재실행 필요:** 조건을 수정해 다시 계산해야 함

## 단계 완료 조건

- 해야 할 작업 완료
- 필요한 결과물 생성
- 결과 파일 위치 기록
- 결과 해석 작성
- 오류와 재실행 여부 기록
- 다음 작업자 시작 위치 기록
- 검토자 확인

대시보드는 Issue 체크 상태를 읽어 단계별 진행률을 표시하도록 구성합니다.
