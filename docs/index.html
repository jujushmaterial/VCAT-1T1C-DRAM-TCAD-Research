HOW TO USE

연구원이 작업하는 순서

  1. 현재 단계 확인대시보드에서 진행 중인 단계와 담당자를 봅니다.
  2. 공동 체크리스트 열기해당 단계의 GitHub Issue에서 해야 할 일을 확인합니다.
  3. 개인 기록 남기기개인 폴더에 코드, 결과, 타임라인과 문제를 기록합니다.
  4. 결과물 확인필요한 코드, 그래프, 표, 해석이 모두 있는지 체크합니다.
  5. 인수인계 후 다음 단계다음 작업자가 시작할 파일과 순서를 적은 뒤 검토를 요청합니다.
