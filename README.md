# VCAT–1T1C DRAM TCAD Research

다중 일함수 게이트를 적용한 VCAT 소자와 1T1C DRAM의 동작, 공정 오차, 허용 범위를 단계별로 검증하기 위한 공동 연구 저장소입니다.

이 저장소는 단순 파일 보관함이 아니라 다음 네 기능을 함께 수행합니다.

1. **Run Sheet**: 현재 해야 할 작업과 완료 조건 확인
2. **연구 대시보드**: 전체 단계, 담당자, 진행률, 문제 상황 확인
3. **개인 작업 기록**: 연구원별 코드, 중간 결과, 타임라인, 인수인계 기록
4. **공용 기준 자료**: 검토가 끝난 코드, 조건표, 결과, 보고서 보관

## 연구 진행 원칙

- 각 단계는 GitHub Issue의 체크리스트를 기준으로 진행합니다.
- 작업을 시작하면 담당자와 상태를 기록합니다.
- 실행이 끝났다는 이유만으로 완료 처리하지 않습니다.
- 필요한 결과물과 해석이 모두 준비된 뒤 검토를 거쳐 완료합니다.
- 개인 작업 파일은 `members/`에, 검토된 기준 파일은 `shared/`에 둡니다.
- 대용량 TDR, PLT, DAT, LOG 파일은 연구실 서버에 두고 저장 위치만 기록합니다.

## 전체 연구 단계

1. 기존 Planar 구조의 작동 원인 확인
2. Single-Metal VCAT 기준 소자 구축
3. VCAT 후보 구조 넓게 비교
4. 초기 1T1C DRAM 동작 확인
5. 후보 구조 세밀 최적화
6. SProcess 공정 흐름 구축
7. 공정 오차 분석
8. 공정 허용범위 지도 작성
9. 최종 1T1C DRAM 검증

## 주요 폴더

- `docs/`: HTML 연구 대시보드
- `runsheet/`: Run Sheet 운영 설명과 단계 자료
- `members/`: 연구원별 개인 작업 폴더
- `shared/`: 검토 완료된 공용 코드와 결과
- `templates/`: 작업 기록, 결과 정리, 인수인계 양식
- `scripts/`: 대시보드 상태 동기화 도구
- `data_manifest/`: 연구실 서버 원본 데이터 위치 기록

## 작업 시작 방법

1. `docs/`의 대시보드에서 현재 진행 단계를 확인합니다.
2. 해당 단계의 GitHub Issue를 엽니다.
3. 담당자를 지정하고 작업 상태를 기록합니다.
4. 개인 폴더에 작업 기록과 파일을 남깁니다.
5. 결과물과 인수인계를 작성한 뒤 검토를 요청합니다.
6. 검토가 끝난 자료만 `shared/`에 반영합니다.

> 현재 저장소는 초기 구축 단계입니다. 대시보드와 단계별 Run Sheet가 순서대로 추가됩니다.
